# Tools and Libraries

## 1. Crossref

- **Purpose:** Scholarly metadata lookup and DOI registration metadata.
- **Use in project:** Primary verification source for DOI-bearing references.
- **Official:** https://www.crossref.org/

## 2. OpenAlex

- **Purpose:** Open scholarly metadata and works graph.
- **Use in project:** Cross-check title, authors, year, venue and identifiers.
- **Official:** https://openalex.org/

## 3. Semantic Scholar

- **Purpose:** Scholarly search and citation graph.
- **Use in project:** Secondary verification and discovery.
- **Official:** https://www.semanticscholar.org/

## 4. DOI Foundation / DOI Resolver

- **Purpose:** DOI registration and resolution.
- **Use in project:** Determine whether a supplied DOI resolves and whether it points to the claimed work.
- **Official:** https://www.doi.org/

## 5. PubMed

- **Purpose:** Biomedical literature indexing.
- **Use in project:** High-value verification source for medical/biomedical references.
- **Official:** https://pubmed.ncbi.nlm.nih.gov/

## 6. Unpaywall

- **Purpose:** Find legitimate open-access locations for scholarly articles.
- **Use in project:** Locate legal full-text copies after a work has been verified.
- **Official:** https://unpaywall.org/

## 7. RAGAS

- **Purpose:** Evaluation framework for retrieval-augmented generation.
- **Use in project:** Useful for broader evaluation of retrieval and generation quality.
- **Project:** https://github.com/explodinggradients/ragas
