# Tools and Libraries

## Crossref
Scholarly DOI and bibliographic metadata verification.
- https://www.crossref.org/

## OpenAlex
Open scholarly metadata graph for title, author, venue and identifier cross-checking.
- https://openalex.org/

## DOI
Persistent identifier resolution for checking whether a supplied DOI maps to the claimed work.
- https://www.doi.org/

## PubMed
Biomedical literature index, particularly useful for medical citation audits.
- https://pubmed.ncbi.nlm.nih.gov/

## urlhealth
Open-source tool for distinguishing live, dead, stale and likely-hallucinated citation URLs using HTTP checks and the Wayback Machine.
- https://github.com/delip/urlhealth

## CiteVerifier / GhostCite
Large-scale citation verification framework accompanying GhostCite.
- https://github.com/TochusC/GhostCite

## ALCE
Automatic citation-evaluation toolkit for citation-supported generation.
- https://github.com/princeton-nlp/ALCE
